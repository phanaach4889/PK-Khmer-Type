Overview & Philosophy

#

Typing in Khmer is notoriously challenging for newcomers. Unlike simple alphabet systems, Khmer is an abugida script with 33 consonants, 23 dependent vowels, 14 independent vowels, and stacked subscript consonants (Coeng ្). Most available learning materials are static poster images that users have to squint at without any feedback.

The Core Philosophy: Authentic muscle memory is built one honest keystroke at a time. Every lesson, every key mapping, and every line of code was crafted from scratch by hand to give learners clear visual guidance, instant auditory feedback, and targeted repetition without shortcuts.
Live Virtual Keyboard
Illuminates the exact target key, modifier state (Shift, AltGr, Coeng), and translucent finger indicator on every character.
Dynamic Keybr-Style Engine
Tracks per-letter speed and accuracy in real-time. Mistake penalty is -3%, while correct strokes award speed-dependent gains up to +5%.
Strict 100% Gatekeeping
Next letters and lesson levels remain locked until all active units hit 100% completion, ensuring durable mastery before advancement.

Keyboard Layouts & Mapping

#

PK Khmer Type provides full curriculum and interactive visualizer support for three standard layouts:

Khmer Standard (Unicode Standard Layout):
The official government and educational standard layout. Consonants and vowels are arranged phonetically across 5 rows. In Khmer Standard, pressing Space inserts the Coeng marker (្ U+17D2) to produce subscript consonants. To insert an actual word space, press Shift + Space.
Khmer NiDA (National Information Development Authority):
Designed for touch-typists transitioning from typewriter layouts. Focuses on the home row for the most frequent consonants. In NiDA, the Coeng subscript marker is typed with Shift + J. Pressing Shift + Space produces a visible word space.
English US QWERTY:
Standard international QWERTY layout. Follows the classical touch-typing curriculum starting with home row anchor keys (f, j), expanding outward through top and bottom rows, capital letters with Shift, and punctuation.

Khmer Typing Mechanics & Rules

#

Understanding the grammatical order of the Khmer Unicode engine is critical for clean typing without broken glyphs or dotted circles:

Golden Rule 1: Base Consonant First
Even if a vowel visually appears to the left of the consonant (e.g. ស្រៈ េ in គេ), you MUST ALWAYS type the base consonant first, followed by the vowel.
ក (K) + ា (A) = កា · គ (K) + េ (E) = គេ
Golden Rule 2: Subscripts (Coeng ្)
To type a subscript consonant below another, press the Coeng trigger key, followed by the consonant to be subscripted.
Khmer Standard: ក + Space + ខ = ក្ខ
Khmer NiDA: ក + (Shift+J) + ខ = ក្ខ
Golden Rule 3: Word Spacing
Khmer text does not use spaces between individual words, but uses spaces between clauses or sentences. Press Shift + Space on both Khmer Standard and NiDA layouts to insert a visible space.

Modifier Layers Architecture

#

Because Khmer has more than 70 unique graphemes, physical keys are partitioned across four modifier layers:

Layer Trigger Contents
Base None (type directly) High-frequency consonants, common vowels (ា, ិ, ី, ឹ, ឺ, ុ, ូ, េ, ោ), Bantoc (់)
Shift Shift (hold) Secondary consonants (ឃ, ឈ, ឍ, ឡ, គ, ជ), compound vowels (ែ, ៃ, ៅ, ាំ, ំ, ះ), visible space
AltGr Right Alt (AltGr) Rare punctuation, Khmer currency symbol (៛), Camnuc Pikuu (៖), independent vowels
Ctrl Ctrl (hold) Specialized religious and archaic Khmer symbols

Adaptive Practice Engine (Keybr-Style)

#

Adaptive Practice is a continuous, intelligent drill generator inspired by Keybr. Rather than memorizing static paragraphs, the engine generates pseudo-words and real vocabulary targeting the learner's weakest letters.

Engine Rule Specification Rationale
Mistake Penalty -3% score per wrong stroke Quickly flags hesitation and inaccuracy without completely wiping out progress.
Fast Keystroke Gain (<300ms) +5% score Rewards genuine muscle memory and fluid touch-typing response.
Normal Keystroke Gain (300–600ms) +3% score Steady progression at comfortable typing cadence.
Slow Keystroke Gain (600–1000ms) +2% score Recognizes correct identification while encouraging speed.
Very Slow Keystroke Gain (>1000ms) +1% score Prevents stalling while nudging the learner toward confidence.
Strict 100% Unlock Gate Next letter locked until ALL active letters = 100% Prevents premature advancement. Learners must thoroughly master all current letters.
Continuous Flow Zero popup modals between rounds Maintains unbroken typing rhythm. Rounds advance automatically with subtle inline toasts.

Frequently Asked Questions (FAQ)

#
Q: Why do some Khmer vowels show a dotted circle (◌)?
Khmer dependent vowels (ស្រៈនិស្ស័យ) cannot stand alone in Unicode. When displayed in isolation on a keyboard key, a dotted circle (U+25CC) is deliberately added so the vowel mark renders clearly instead of collapsing into an illegible dot.
Q: Can I use PK Khmer Type completely offline?
Yes! PK Khmer Type is a Progressive Web App (PWA). All layout definitions, audio synthesizers, 3D models, and 218 lessons are completely bundled locally in vanilla JavaScript. You can save or bookmark the page and practice with zero internet connection.
Q: How do I export or backup my typing progress?
Open the Settings menu (or click the gear icon in the top right), then click "Export Backup (JSON)". You can import this file anytime to restore your completed lessons, stats, and badges on another computer or browser.
