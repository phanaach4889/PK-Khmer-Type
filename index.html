    PK Khmer Type — demo account system

    This is a demo account system. No real personal data should be entered — accounts exist only in this browser.

    01Where your data lives

    Everything you enter — username, email, and a hashed password — is saved to this browser's local storage. Nothing is sent to a server, and nothing leaves this device.

    02Password handling

    Passwords are never stored as plain text. Each one is combined with a random salt and hashed with SHA-256 before it touches storage. This is still not real-world security — it simply avoids the most obvious mistake.

    03Staying signed in

    Once you sign in, your session is kept on this device until you explicitly sign out — including after refreshing the page or navigating back and forward.

    04Clearing your data

    Clearing your browser's site data, using a different browser, or switching devices will remove your demo account. There is no recovery — this is a local-only trainer, not a hosted service.

      A Note From the Developer

      •

      This website is made with care and high quality — built to be the best free way to learn how to type Khmer and English, one honest keystroke at a time. Every lesson, every layout, and every line of code was crafted by hand, not copied from a template. If it helps you type a little faster or feel a little closer to your own language, then it did its job. Thank you for practicing here.

      Made by a 14-year-old student — still learning, still building, one project at a time. I don't have a big team or a company behind me, just a desktop computer, a lot of late nights, and a genuine love for the Khmer language and for code. If you're young and want to build something too: start small, keep going, and don't wait until you feel "ready." You already are.

      I built this because I noticed how few good, free tools exist for learning the Khmer keyboard layout — most guides are just static pictures you have to squint at. So I set out to make the one I wished I had: something you can actually practice on, layer by layer, key by key, until it's muscle memory. It's still growing. Lessons, the leaderboard, new themes — all of it gets built a little at a time, between homework and sleep.

      Found a bug, or have an idea for a lesson you wish existed? I read every message on Facebook. This site isn't going anywhere — I'm planning to keep adding to it for as long as it's useful to someone.

      • One more thing, before you go

      Since you've read this far, do me a favor — don't get up yet. Sit back down, hands on home row, and finish the drill you were on. Muscle memory isn't built during the breaks; it's built in the next ninety seconds. Ten more words. One more layer. That's it. Whatever pulled you away can wait a minute longer, and future-you will thank you for staying in the seat.

      • 14 y/o · Student Developer

      — Phanna Kurosaki, founder & developer

      How to Get & Switch to Khmer NiDA Keyboard

      Setup instructions for Windows, Mac & Mobile to practice authentic touch typing.

      Instant Language Switch Shortcuts:
      Windows 11 / 10 ⊞ Win + Space or Alt + Shift
      macOS (Apple Mac) Ctrl + Space or Globe
      Mobile (Android / iOS) Tap the Globe icon on keyboard
      Recommended — No Download Required!

      Windows 10 and Windows 11 already have the official Khmer NiDA keyboard included for free by Microsoft. You only need to add it in Windows Settings once:

      1. 1
        Open Windows Settings

        Press Win + I on your keyboard to open Windows Settings.

      2. 2
        Go to Time & Language

        Select Time & Language from the left menu, then click Language & Region (or Language on Windows 10).

      3. 3
        Add Khmer Language

        Click Add a language, type Khmer or ភាសាខ្មែរ, choose Khmer (Cambodia), and click Install.

      4. 4
        Switch & Start Typing!

        Press Win + Space anytime to switch between English and Khmer NiDA!

      If you are using Windows 7, 8, 10, or prefer the traditional Open Institute / KhemaraSoft installer package, you can download the official Khmer Unicode NiDA keyboard installer below:

      KhemaraSoft Khmer Unicode Installer Official Khmer Keyboard Installer for Windows (32/64-bit)
      Visit Download
      Open Institute Khmer Software Initiative Original National NiDA Keyboard Package & Khmer Fonts
      Visit Download
      1. 1
        Run Setup.exe

        Extract the downloaded zip archive, right click Setup.exe and select Run as administrator.

      2. 2
        Restart or Log Out

        After the installation finishes, restart your PC or log out to let Windows load the new keyboard driver.

      3. 3
        Switch using Alt + Shift or Win + Space

        Select Khmer NiDA from your taskbar language bar or press Alt + Shift.

      Apple Mac computers have official Khmer keyboard support built directly into macOS:

      1. 1
        Open System Settings

        Click the Apple menu > System Settings (or System Preferences).

      2. 2
        Navigate to Keyboard > Input Sources

        Click Keyboard in the sidebar, find Text Input, and click Edit... next to Input Sources.

      3. 3
        Add Khmer

        Click + (Add), search Khmer, select Khmer, and click Add.

      4. 4
        Switch with Control + Space

        Press Control + Space or the Globe key on modern Mac keyboards to switch instantly.

      How to enable Khmer NiDA typing on mobile phones and tablets:

      Android (Google Gboard)

      1. Install Gboard from Google Play Store if not already installed.
      2. Open Gboard Settings > Languages > Add keyboard.
      3. Search Khmer and select Khmer (Cambodia).
      4. Tap the Globe icon on the keyboard to switch languages.

      iPhone & iPad (iOS)

      1. Open Settings > General > Keyboard.
      2. Tap Keyboards > Add New Keyboard...
      3. Scroll down and choose Khmer.
      4. Tap the Globe key at the bottom left to switch.
