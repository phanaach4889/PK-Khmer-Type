System Areas
What each branch of the map actually contains
Curriculumkeyboard.json + generators → 218 lessons across English/NiDA/Standard. Complete through Phase 9; expansion in P11.
Khmer NiDAHeaviest track (77 lessons, 13 levels) — coeng/subscript combining, type-after-display vowel order. Curriculum done; adaptive parity is P12.
PracticeLesson, normal, drills, weak-key/error, mixed, review, challenge, races, Focus Mode, mastery checks. Base loop done; drill coverage expands in P11.
Adaptive PracticeClosed loop: collect → analyze → find weak areas → targeted practice → measure → update state → repeat. Works, but isolated from Khmer — unified in P12.
Progress / DataAccuracy, speed, errors, weak keys/combos, history, mastery — khmerProgressData_v2. Shared input for Review, Adaptive, Checkpoints. Done.
Typing EngineInput handling, character comparison, timing, backspace, special chars, sound, focus/persistence. Stable — not scheduled for rebuild.
UI / UXNavigation, progress display, feedback, Focus Mode. Baseline exists; full a11y and state coverage is P13.
Testing & Validationvalidate_curriculum.js gate always active; full-system E2E/regression/a11y verification is P14.
Dependencies
  • Phase 10 depends only on Phase 9 (done) — can start immediately.
  • Phase 11 depends on the validated curriculum bundle staying green under validate_curriculum.js.
  • Phase 12 depends on Progress/Data and Review's weak-key detection (both done) — blocked on engineering time, not missing data.
  • Phase 13 depends on P10–P12's UI surfaces being stable, to avoid redoing string/ARIA work.
  • Phase 14 depends on everything above being functionally done — it tests the union.
  • Phase 15 depends on Phase 14 passing clean.
  • Every branch (Curriculum, Practice, Engine) passes through the validate_curriculum.js gate before reaching Progress/Data — it is never bypassed.

Completion Definition
  • All 218 lessons (English, NiDA, Standard) pass validate_curriculum.js with 0 errors.
  • Khmer NiDA has full coverage keys→mastery, including coeng/vowel-order rules — no invented rules.
  • Lesson progression is logical: prerequisites hold, ≥90% checkpoints gate advancement.
  • Practice works across drills, review, races, Focus Mode for all three layouts.
  • Adaptive Practice runs identically for English, NiDA, Standard — no isolated state.
  • Progress tracking is reliable and persists correctly.
  • Accuracy/speed/error tracking is correct across the typing engine.
  • Accessibility has been checked, not assumed.
  • Full regression suite (218-lesson E2E, cross-browser, orthography stress) is green.
  • No known major curriculum gaps remain undocumented.
